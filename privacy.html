Política de privacidad

Rclone Personal Storage es una configuración OAuth destinada al uso personal de su propietario.

La aplicación utiliza Google Drive API para acceder a archivos, metadatos y carpetas con fines de respaldo, sincronización y recuperación.

El acceso requiere autorización del titular de la cuenta Google. Los tokens OAuth se almacenan en los equipos configurados por el propietario.

La aplicación no vende datos personales, no ofrece acceso público a los archivos y no incorpora sistemas propios de seguimiento de visitantes.

El titular puede revocar el acceso desde la configuración de seguridad de su cuenta de Google.

Este sitio se aloja en GitHub Pages, sujeto a las políticas de GitHub.

Condiciones de uso

Esta aplicación es de uso personal. No se ofrece como servicio a terceros.

Utiliza rclone, una herramienta de código abierto independiente de Google.
